# 0.4.2 — 2026-06-30

Site shell and landing-page polish. Frontend is **0.4.2**. Wraps the v0.4.1 wizard in a full-page layout with animated backdrop, marketing hero, per-step section headers, and trust notes on the input screen. No pipeline or API changes.

### Frontend (Web `0.4.2`)

- **Site shell (`SiteChrome.tsx`):** `SiteShell`, sticky glass header + step nav, footer; theme toggle moved into header brand row.
- **Animated backdrop:** blurred glow orbs, three drifting SVG blobs, subtle film grain; hero vignette on input/running; **calm** mode dims background on result steps for readability.
- **Input hero:** eyebrow, headline, and lead copy on the starting page (no O\*NET in user-facing text).
- **Step section heroes:** title + lead on running and each result step (profile → jobs).
- **Input panel:** narrower centered card (`28rem`); resume toolbar and Go centered; visible **Resume** label removed — **Choose resume file** button with `aria-label`s on file input and textarea.
- **Trust notes:** privacy (“we don’t save or keep your resume”) and pricing (“doesn’t cost you anything, but donations are always appreciated”) below the input panel.
- **Styles:** site layout tokens (`--site-glass-bg`, glow/blob colors); `prefers-reduced-motion` disables blob drift.

### Backend

- No changes.
