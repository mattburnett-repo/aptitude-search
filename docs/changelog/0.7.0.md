# 0.7.0 — 2026-07-05

Optional Sentry error reporting for the FastAPI backend when `SENTRY_DSN` is set. No pipeline or frontend changes.

### Frontend

- No changes.

### Backend

- **`sentry-sdk[fastapi]`** — optional init via `SENTRY_DSN` / `SENTRY_ENVIRONMENT` env vars (`send_default_pii=False`, errors only).
- **`main.py`** — FastAPI integration; `capture_exception` on unhandled 500s.
- **`stream_pipeline.py`** — `capture_exception` on streaming pipeline failures (primary UI path).
