# 0.7.1 — 2026-07-31

Exclude flaky Mojeek from Stage 3 web search. Search engines are now configured via `job_discovery.search_backends`.

### Frontend

- No changes.

### Backend

- **`job_discovery.search_backends`** — comma-joined list passed to `ddgs.text(..., backend=...)` so discovery no longer uses `auto` (which included Mojeek).
- Default engines: `bing`, `brave`, `duckduckgo`, `google`, `yahoo`, `yandex`, `wikipedia` (Mojeek omitted).
- Mojeek timeouts previously could bubble as `TimeoutException` and fail streamed `/v1/pipeline` runs.

### Tests

- `test_search_job_postings.py` — fake DDGS accepts `backend`; asserts configured backends are passed through.
