# 0.8.1 — 2026-08-08

Simplify Stage 3 discovery for higher recall: keep more search hits, rank by aptitude fit to a top-k list, then synthesize match explanations. Remove leftover smolagents wiring from the production app path.

### Frontend

- No changes.

### Backend

- **Discovery** — `search_job_postings` returns filtered SERP rows as jobs (no scrape / ATS allowlist gate). Junk denylist only (`url-filters.toml`).
- **Aptitude fit** — rank + `job_discovery.result_top_k` (default 25); removed `aptitude_fit_min_score` / `aptitude_fit_min_results`.
- **Pipeline** — dropped extra `filter_found_jobs` and tool-observed URL filtering on the production path.
- **Synthesis** — still LLM-based match explanations; now passes `llm.job_discovery.max_tokens` (default 8192) so larger top-k result sets do not truncate.
- **Deps / telemetry** — removed `openinference-instrumentation-smolagents` and `SmolagentsInstrumentor` from the app. `smolagents` retained for `lg_spike/` only.
- **`lg_spike/`** — unchanged.

### Tests

- Updated discovery, URL-filter, aptitude-fit, pipeline, and synthesis tests for the simplified Stage 3 path.

- **`docs/PROMPT-CONTRACT.md`**, **`backend/README.md`**, root README badge — Stage 3 described as search → rank → synthesis.
