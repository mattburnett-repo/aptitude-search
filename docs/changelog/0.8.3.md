# 0.8.3 — 2026-08-13

Resume-inferred culture preferences and interests as job-search inputs, plus backend orchestration cleanup. Frontend is **0.8.3**.

### Frontend

- Aptitude profile shows `culture_preferences` and `interests` when non-empty.
- Stage 1 lead copy mentions those signals.
- Collapsed Stage 2/3 result cards (PDF export retained).
- Package version **0.8.3**.

### Backend

- **Profile** — required `culture_preferences` and `interests` (labeled items; `[]` if no evidence). Stage 1/2 prompts and synthesis cite them.
- **Search** — interests as discovery fallback query tokens; culture preferences in Stage 2 avoid/families and Stage 3 fit ranking. Not used as “mission-driven jobs” Tavily queries.
- **Swagger default** — `civic-climate-product-engineer.txt` via `pipeline-request-example.json`.
- **Cleanup** (this branch since 0.8.2) — Stage 2 in `pipeline.py`; thinner `main.py`; tighter Stage 1 normalizer; `pytest-watcher` in backend dev deps.

### Tests

- Discovery and aptitude-fit coverage for the new fields; fixture/schema validation; Swagger example matches the sample resume; frontend profile display/PDF assertions.
