# 0.3.1 — 2026-06-30

Embedding matchability release. Frontend is **0.3.1**. Improves O\*NET occupation vectors and Stage 1 query embedding so Stage 2 vector search aligns better with work-pattern language and market titles.

### Matching (embed edge)

- **O\*NET mashup:** `occupation_profile_from_onet.sql` now includes top-10 **`work_activities`** (Importance scale) per occupation, alongside title, description, abilities, skills, and alternate job titles.
- **Aptitude embed:** Stage 1 vector search now includes **`adjacent_roles`** in `aptitude_text_for_embedding()` (with summary, strengths, and working-style signals).
- **SQL fix:** `abilities` lateral subquery uses `LEFT JOIN LATERAL` so the mashup runs on Postgres.
- **Rebuild required:** re-run `data/embed/build_occupation_embeddings.py` after deploy so `occupation_embeddings` reflects the new mashup (runtime aptitude change needs no re-embed).

### Data (O\*NET corpus)

- **Embed-only load:** `ONET_EMBED_ONLY=1` now includes `work_activities` (8 tables, ~290k INSERTs).
- **Removed** unused stub `data/embed/occupation_embeddings.sql` (DDL lives in `create-occupation-embeddings-table.sh`).
- **Smoke test:** embed-only table set and row counts updated for `work_activities`.

### Backend

- **`PipelineResult` TypedDict** on `run_pipeline()` return type.
- **Tests:** `test_embedding.py` covers `adjacent_roles` in aptitude embed text.

### Frontend (Web `0.3.1`)

- **Version bump** to 0.3.1 (no UI changes in this release).

### Documentation

- **`docs/v0.3.1/embedding-matchability-gaps.md`** — fields on/off the embed edge; updated after `work_activities` and `adjacent_roles` land.
- **`docs/v0.3.1/stage-pages-ux.md`** — wizard UX design notes (moved from `frontend/docs/`).
- **`docs/changelog/0.3.0.md`** — embed tooling line names `create-occupation-embeddings-table.sh`.

### Operational note

After pulling this release, rebuild occupation embeddings on any Postgres instance that powers Stage 2 matching:

```bash
backend/.venv/bin/python data/embed/build_occupation_embeddings.py
```

Restart the API so runtime aptitude embedding picks up `adjacent_roles`.
