# 0.6.0 — 2026-07-02

Optional Buy Me a Coffee support on the frontend. Frontend is **0.6.0**. No pipeline or API changes.

### Frontend

- **Support config:** `VITE_SUPPORT_URL` (defaults in `.env.development` / `.env.production` → `https://buymeacoffee.com/aptitude.search`); `frontend/src/config/support.ts` derives BMC slug from URL.
- **Trust notes:** “Donations” on the input screen links to BMC when configured (`SupportLink.tsx`).
- **Footer:** BMC button embed via `buyMeACoffee.ts` (loads script once, calls `window.bmcBtnWidget` — avoids broken dynamic `document.writeln` injection); scaled-down footer styling.
- **Jobs step:** quiet support footnote after job cards when results exist; hidden on zero results; excluded from PDF export.
- **Styles:** `.support-link`, `.site-footer-bmc`, `.verified-results-support`.

### Backend

- No changes.
