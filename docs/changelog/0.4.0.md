# 0.4.0 — 2026-06-30

Stage-pages wizard release. Frontend is **0.4.0**. Replaces the single long scroll with a presentation-only wizard: one screen at a time, same `POST /v1/pipeline` flow.

### Frontend (Web `0.4.0`)

- **Wizard navigation:** `view` state drives `input` → `running` → five result steps (`stage1`–`stage5`). Back / Next / Start over; only one panel visible at a time; all step panels stay mounted so scroll, `<details>`, and PDF toolbar state survive navigation.
- **Step 1 — From your resume:** `AptitudeProfileDisplay` (inference confidence removed from this step).
- **Step 2 — How sure we are:** new `InferenceConfidenceDisplay` with **Save as PDF** (`exportInferenceConfidencePdf.ts`).
- **Step 3 — Matching careers:** `OccupationMatchesDisplay` (standalone step).
- **Step 4 — Recommended roles:** `RoleFamilyPlanDisplay` (standalone step; updated copy and per-role labels).
- **Step 5 — Job search results:** `VerifiedMatchesDisplay` (“What we looked for” heading).
- **Running screen:** progress log only; **Next** when the pipeline finishes (no Back). Stage 1 **Back** returns to Running.
- **Stage nav chrome:** `SaveAsPdfToolbar` and bottom `StageBottomNav` share Back / Next / Start over; nav disabled while PDF export is in progress.
- **Pipeline hook:** run-id guard in `usePipeline` ignores stale completions after Start over or a new run.
- **Optional constraints** UI commented out; pipeline still sends `defaultConstraints`.
- **Raw JSON** collapsibles commented out in all result displays (preserved in source).
- **Styles:** Save as PDF = primary blue; Back = amber; Start over = green; progress log grows without a scroll cap.
- **Tests:** updated display tests; new stale-pipeline test in `usePipeline.test.tsx`.

### Backend

- **Progress copy:** Stage 3 synthesis message → “Preparing verified job listings…” (user-facing pipeline log only; no API change).
