# 0.8.2 — 2026-08-09

Finish SERP-only Stage 3 discovery: plain Tavily search with domain filters, optional score floor, and snippets; move scrape/spike helpers out of the production app into `notebooks/`.

### Frontend

- No changes.

### Backend

- **Discovery** — `search_job_postings` is a plain function (no SearchJobPostings class / JSON tool envelope). Tavily search returns filtered SERP rows as `found_jobs` (title, URL, optional snippet).
- **Tavily options** — `job_discovery.search_depth` and `job_discovery.search_min_score`; pass `exclude_domains` / optional `include_domains` from `url-filters.toml`.
- **URL utils** — `normalize_result_url` replaces scrape-oriented helpers; removed production `page_extract` and `tool_observed_urls`.
- **Config** — dropped scrape-only `llm.job_discovery` fields (`visit_max_output_length`, `search_scrape_max`, `page_snippet_max_chars`).
- **Deps** — `smolagents` / `ddgs` kept in `requirements-dev.txt` for notebooks only.
- **`notebooks/`** — relocated from `lg_spike/`; spike scrape/URL helpers and Tavily certification notebook live here.

### Tests

- Updated search, URL-utils, URL-filter, discovery, and aptitude-fit tests for SERP-only discovery and Tavily domain/score options.

### Documentation

- Aligned product-model rule, PROMPT-CONTRACT, and Tavily migration notes with search-only Stage 3.
- Renamed release slash command docs to `commit-tag-push`.
