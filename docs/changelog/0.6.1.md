# 0.6.1 — 2026-07-02

Lighthouse and security polish for the v0.6.0 support UI. Frontend is **0.6.1**. No pipeline or API changes.

### Frontend

- **Footer BMC button:** replaced third-party `button.prod.min.js` embed with a static `BuyMeACoffeeButton` link styled like the v0.6.0 widget (no third-party cookies on load).
- **Security headers:** `frontend/vercel.json` — CSP, COOP, XFO, nosniff, Referrer-Policy, Permissions-Policy (Vercel production only).
- **CSP:** theme bootstrap moved from inline script to `public/theme-init.js`.
- **SEO:** `<meta name="description">` in `index.html`.
- **Fonts:** Cookie family retained for footer button label.
- **Removed:** `buyMeACoffee.ts`, `bmcBtnWidget` wiring, related tests.

### Backend

- No changes.

### Tests

- `BuyMeACoffeeButton.test.tsx`; updated `SiteChrome.test.tsx`.
