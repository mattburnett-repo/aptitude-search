# 0.1.0 — 2026-06-23

Initial release. Frontend and backend are both **0.1.0**. This version implements the full basic product workflow and the infrastructure needed to run, configure, test, and extend it.

### Product

- **Two-stage opportunity discovery:** resume → aptitude profile (Stage 1) → profile-driven job search → `verified_matches` (Stage 2), with no manual step between stages.
- **Aptitude-driven matching** instead of keyword-only search: Stage 1 infers capabilities from resume text; Stage 2 discovers and verifies openings aligned to that profile.
- **Optional search constraints:** location, remote preference, minimum salary, and industry include/exclude lists (`schemas/constraints.schema.json`).

### Backend (API `0.1.0`)

- **FastAPI service** on port 3001 with Swagger UI at `/docs`.
- **Endpoints:**
  - `GET /health` — liveness check
  - `POST /v1/pipeline` — full pipeline (`aptitude_profile` + `verified_matches`)
  - `POST /v1/stages/1` — Stage 1 only
  - `POST /v1/stages/2` — Stage 2 only (requires aptitude profile)
- **Stage 1:** Hugging Face chat completion using `prompts/01-resume-to-aptitude-profile.md`; output validated against `schemas/aptitude-profile.schema.json`.
- **Stage 2a (discovery):** Python-driven query planning from profile + constraints; `search_job_postings` (DuckDuckGo search, URL filters, page scrape) — no LLM for discovery.
- **Stage 2b (synthesis):** Hugging Face chat completion using `prompts/03-job-discovery-synthesis.md`; output validated against `schemas/job-discovery-results.schema.json`; result URLs limited to tool-observed links.
- **Streaming progress:** `POST /v1/pipeline?stream=1` emits NDJSON progress events for UI consumption.
- **Resume input:** plain text or base64-encoded PDF (`resume_pdf_base64`), extracted server-side.
- **Configuration:** `config.toml` for LLM keys/models, discovery limits, prompt filenames, schema paths, and CORS.
- **URL filtering:** configurable skip lists in `app/job_discovery/url-filters.toml`.
- **Request context:** request IDs on responses and structured error handling.
- **Observability:** OpenTelemetry tracing with smolagents instrumentation.
- **Automated tests:** offline pytest suite (mocked, no live LLM); golden Stage 1 fixture validation script; optional Stage 2 discovery smoke script.

### Frontend (Web `0.1.0`)

- **Single-page MVP** (Vite + React + TypeScript) on port 5173.
- **Resume input:** paste text or upload `.txt`, `.md`, or `.pdf`.
- **Optional constraints** form matching the API schema.
- **Run pipeline (1 → 2):** single streamed request with live progress log.
- **Results panels:** expandable aptitude profile and verified matches views (formatted display + raw JSON).
- **Save as PDF** for aptitude profile and verified matches panels.
- **Light/dark theme** toggle.
- **Dev proxy:** `/api/*` → API on `localhost:3001` (direct API URL override via `VITE_API_URL`).
- **Automated tests:** Vitest suite for components, hooks, and API client.

### Shared infrastructure

- **JSON Schemas:** `aptitude-profile`, `job-discovery-results`, `constraints` under `schemas/`.
- **Prompt pack v1.0.0:** Stage 1 and Stage 2 synthesis prompts under `prompts/`; contract documented in `docs/PROMPT-CONTRACT.md`.
- **Fixtures:** sample resumes, pipeline request example, and Stage 1 golden output under `fixtures/`.
- **Documentation:** root README, backend/frontend READMEs, `docs/WORKFLOW.md`, `docs/TESTING.md`, `docs/PROMPT-CONTRACT.md`, and versioned release notes under `docs/changelog/`.
