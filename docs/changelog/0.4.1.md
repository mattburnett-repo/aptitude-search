# 0.4.1 — 2026-06-30

Frontend styling release. Frontend is **0.4.1**. Appearance-only pass on the v0.4.0 wizard: WorqAI-inspired palette, step nav, and running-screen polish. No pipeline or API changes.

### Frontend (Web `0.4.1`)

- **Visual system:** Inter UI font; JetBrains Mono for progress log; zinc dark-first palette with green accent; dark/white primary CTAs (replaces Google blue).
- **Default theme:** dark when `localStorage.theme` is unset (`index.html`, `useTheme.ts`).
- **Page shell:** tagline, header separation, light-mode header gradient and card shadows.
- **Input screen:** 01/02/03 step strip; resume + Go in `.input-panel` card; **Go →** primary CTA.
- **Running screen:** `Stage N of 3 — …` label from progress messages; spinner; terminal-style log (`>` active, `✓` complete); overflow fix for log prefixes inside collapsible.
- **Step indicator nav:** clickable pills (Profile → Confidence → Matches → Roles → Jobs) after results arrive; active-step highlight; disabled during run/PDF export; no text-selection flash on click.
- **Result panels:** flat bordered cards; aptitude summary green accent bar; high-confidence job cards green left border; role-family and occupation match card styling.
- **Buttons:** `.primary-cta` for Go/Next →; amber Back; green Start over unchanged in role.
- **PDF export:** light override blocks unchanged.
- **Tests:** button labels updated for **Go →**.

### Backend

- No changes.
