# 0.8.0 — 2026-08-08

Replace Stage 3 web discovery’s fragile `ddgs` + `VisitWebpageTool` stack with Tavily search (extract briefly in scope; **0.8.1** kept search/SERP-only). Faster, more reliable discovery for `/v1/pipeline`, with a provider-shaped seam for future search work (including semantic search).

### Frontend

- No changes.

### Backend

- **Tavily discovery** — `app/job_discovery/tools.py` uses `TavilySdkClient` for web search (initially search + extract; **0.8.1** simplified to SERP-only). `search_job_postings` JSON contract unchanged (`jobs` / `skipped` / `message`).
- **Config** — `job_discovery.tavily_api_key` required; removed `job_discovery.search_backends` (ddgs engines). Dropped unused `page_summary_max_chars` / `page_bullet_max_count`.
- **Deps** — `tavily-python` for production discovery; `ddgs` retained only for `notebooks/` until that spike is ported.
- **Schema validation** — removed deprecated `jsonschema.RefResolver`; validators use `Draft202012Validator` with local `$defs` only.
- **Dead code** — removed unused `job_page_json_for_agent` / `compact_job_page_for_agent`, and the unused `system_prompt_stage3()` alias.
- **`notebooks/`** — still DDGS-based; engines are spike-local (no longer read from config). Not the production path.

### Tests

- `test_search_job_postings.py` — `_StubTavily` stand-in; asserts search filtering / scrape gating without live Tavily calls.
