# 0.2.0 — 2026-06-24

Aptitude refinement release. Frontend and backend are both **0.2.0**. This version shifts job discovery from skill-keyword search toward role-family and work-pattern matching, and adds Stage 1.5 between profile extraction and job search.

### Product

- **Three-stage pipeline:** resume → aptitude profile (Stage 1) → role family plan (Stage 1.5) → profile-driven job search → `verified_matches` (Stage 2).
- **Role-family–driven discovery:** Stage 1.5 produces `recommended_role_families` with `search_terms`, `work_modes`, and `avoid_terms`; discovery uses those terms first instead of raw stack keywords.
- **Adjacent-role fallback:** when no role family plan is supplied to Stage 2 alone, discovery prefers `adjacent_roles`, then `domains`, with skills only as last resort.
- **Work-pattern fit ranking:** scraped jobs are scored and filtered using `strengths`, `working_style_signals`, and role-family `work_modes` / `avoid_terms` before synthesis.
- **Complete synthesis coverage:** every URL in `found_jobs` gets a `results` row; omitted listings are backfilled with fallback match descriptions.
- **Explainable matches:** synthesis prompts and user tasks emphasize work-pattern fit (`strengths`, `working_style_signals`, `aptitude_fit_signals`) over skill overlap alone.

### Backend (API `0.2.0`)

- **New endpoint:** `POST /v1/stages/1.5` — role family plan from aptitude profile.
- **Updated pipeline:** `POST /v1/pipeline` runs Stage 1 → 1.5 → 2 and returns `role_family_plan` alongside `aptitude_profile` and `verified_matches`.
- **Stage 1.5:** Hugging Face chat completion using `prompts/02-role-family-plan.md`; output validated against `schemas/role-family-plan.schema.json`.
- **Discovery:** `discovery.py` builds queries from role-family `search_terms`; occupation-agnostic seniority modifiers replace SWE-specific title defaults.
- **Aptitude fit:** `aptitude_fit.py` ranks and filters `found_jobs`; config: `aptitude_fit_min_score`, `aptitude_fit_min_results`.
- **Synthesis:** updated `prompts/03-job-discovery-synthesis.md` and user task; backfill in `synthesize_verified_matches.py` ensures one result per discovered job.
- **Fixtures & tests:** career-changer role-family plan fixture; tests for aptitude-fit ranking, synthesis backfill, and query planning.

### Frontend (Web `0.2.0`)

- **Pipeline types:** `role_family_plan` included in API response typing (`frontend/src/api/pipeline.ts`).
- **Version bump** to 0.2.0.

### Documentation

- Industry and minimum-salary constraints still not applied in discovery filtering.
