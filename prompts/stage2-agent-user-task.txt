Code pattern — one search per step:
```python
import json
result = json.loads(search_job_postings(query="role skill location"))
for job in result["jobs"]:
    url = job["url"]
    if url in visited_urls:
        continue
    visited_urls.append(url)
    found_jobs.append({
        "title": job["title"],
        "company": job["company"],
        "url": job["url"],
        "location": job["location"],
    })
print(json.dumps(found_jobs[-2:], indent=0))
```
